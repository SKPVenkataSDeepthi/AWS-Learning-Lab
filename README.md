# Overview

This repository documents my journey of designing, building, and experimenting with cloud-native solutions on Amazon Web Services.

Rather than serving as a collection of notes, this repository is organized as a practical engineering workspace where concepts are explored through architecture diagrams, hands-on implementations, infrastructure patterns, automation, and production-inspired projects.

Alongside independent projects, I am also progressing through AWS Skill Builder learning paths and immersive AWS Cloud Quest experiences to deepen my understanding of modern cloud architecture and AWS best practices.
